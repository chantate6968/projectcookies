# lamsumsum cookies Brand UI Guide

## Logo Template Options

1. Atelier Wordmark
   - Lowercase serif wordmark: `lamsumsum cookies`
   - Best for the main website header and premium packaging.

2. Embossed Seal
   - Restrained circular stamp with `LC`, fine cocoa lines, and subtle crumb details.
   - Best for packaging, stickers, gift boxes, and delivery bags.

3. Minimal Bite
   - Abstract bitten-cookie outline with no cartoon expression.
   - Best for social avatars, favicons, and small digital placements.

4. Ribbon Monogram
   - Single-letter `L` monogram with a delicate ribbon curve.
   - Best for seasonal collections, corporate gifts, and premium bundles.

## Step-by-Step Commercial UI Direction

1. Define the promise.
   - Lead with handmade cookies, premium ingredients, fresh delivery, and gifting.

2. Build the visual system.
   - Use ivory backgrounds, cocoa text, taupe body copy, muted gold accents, and generous whitespace.

3. Design the homepage as a sales page.
   - Include a calm hero, restrained promotion, featured cookies, trust signals, reviews, FAQs, and a strong primary call to action.

4. Make product details complete.
   - Show flavor notes, quantity, price, ingredients, allergens, storage, delivery, and gifting options.

5. Make cart and checkout transparent.
   - Show item edits, promo codes, shipping estimates, taxes, totals, payment status, and order confirmation.

6. Validate the customer journey.
   - Test on mobile first, then desktop. Check accessibility, cart math, promotions, and checkout error states.

## Current Recommended First Promotion

Use `SWEETSTART` as a launch promotion for free delivery over `$45`.

This is simple for customers to understand and useful for testing cart totals later.
