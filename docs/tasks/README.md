# Functional Task Folders

Each folder represents one website function and should be built independently where possible.

## Functions

- `marketing`: homepage, promotion, reviews, FAQ, brand story.
- `browse`: product catalog browsing and collection discovery.
- `product-details`: product detail pages, ingredients, allergens, delivery info.
- `cart`: cart state, quantities, promo codes, totals.
- `order`: order review, confirmation, order summary.
- `payment`: payment provider, payment states, transaction flow.
- `support`: support content, policies, allergy guidance, contact paths.

## Recommended Build Order

1. `marketing`
2. `browse`
3. `product-details`
4. `cart`
5. `order`
6. `payment`
7. `support`
