# Support Function

## Customer Goal

Customers can get answers about ingredients, allergens, delivery, gifting, refunds, and order issues.

## Scope

- FAQ.
- Contact section.
- Allergy disclaimer.
- Delivery policy.
- Refund or replacement policy.
- Order support guidance.

## First Build Slice

Create a concise FAQ and support policy section for the homepage or a dedicated support page.

## Design Requirements

- Use calm, clear language.
- Make allergy and delivery information easy to find.
- Avoid legal overpromising until final policies are confirmed.

## Verification

- Common purchase objections are answered.
- Contact/support path is visible.
- Allergy language is not hidden in small text only.
