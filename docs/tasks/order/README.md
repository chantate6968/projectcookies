# Order Function

## Customer Goal

Customers can place an order and receive a clear confirmation with order details.

## Scope

- Order review before payment.
- Customer contact and delivery information.
- Order confirmation page.
- Order number and summary.
- Confirmation email plan.

## First Build Slice

Create a checkout review and order confirmation screen using mock order data.

## Design Requirements

- Make the final review calm and exact.
- Show products, delivery, promo, total, and customer details.
- Confirmation should feel premium and reassuring.

## Verification

- Order summary matches cart totals.
- Confirmation includes next steps and support information.
- Error or incomplete order states are clear.
