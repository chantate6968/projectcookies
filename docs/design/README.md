# Design Ready-To-Go Pack

This folder gathers the current ready design direction for `lamsumsum cookies`.

## Brand Direction

- Positioning: premium cookie atelier for gifting, hosting, and quiet indulgence.
- Audience: high-end customers who value presentation, ingredients, and trust.
- Tone: refined, warm, calm, precise, and commercial.
- Primary logo direction: Embossed Seal for packaging and physical touchpoints.
- Website identity direction: Atelier Wordmark paired with the Embossed Seal.

## Visual System

- Backgrounds: ivory and warm paper tones.
- Text: cocoa brown for headings, taupe for body copy.
- Accent: muted gold for luxury signals and section labels.
- Shape language: clean lines, light borders, restrained circles, generous spacing.
- Avoid: cartoon cookies, loud gradients, heavy shadows, playful colors, cluttered badges.
